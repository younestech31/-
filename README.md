# مواريث — حاسبة المواريث

تطبيق محلي لحساب مسائل المواريث وتصفية التركات مع حفظ الحالات وتصدير التقارير.

## المتطلبات
- Node.js 22
- npm 10.9.9 أو أحدث

## التشغيل

```bash
npm ci
npm run dev
```

## الاختبارات والتحقق

```bash
npm run lint
npx tsc --noEmit
npm test
npm run build
```

## نموذج الترخيص اليدوي

لا يتطلب التطبيق حساب مستخدم أو قاعدة بيانات أو بوابة دفع أو تجديداً تلقائياً. تبقى الحسابات الأساسية والحفظ المحلي والنسخ الاحتياطي متاحة في النسخة المجانية. ترخيص Pro اختياري ومحدد المدة، ويُفعّل باستيراد ملف ترخيص موقّع محلياً.

### تهيئة المفاتيح لدى مالك المنتج

على جهاز موثوق خاص بالمالك فقط:

```bash
npm run license:keys
```

ينشئ الأمر مفتاح ECDSA P-256 خاصاً داخل `.license-keys/` ويضع المفتاح العام فقط في `lib/licensing/public-key.ts`. مجلد المفتاح الخاص مُدرج في `.gitignore`. احتفظ بنسخة احتياطية خارج المستودع. لا تشارك المفتاح الخاص ولا ترفعه إلى Git أو Vercel.

### إصدار ترخيص بعد التحقق اليدوي من التحويل

```bash
npm run license:issue -- --installation-id "<ID>" --customer "اسم المكتب" --days 90
```

ينشئ الأمر ملف `.mwlicense` يرسل يدوياً للعميل. يستورد العميل الملف من صفحة `/license`. لا تتم أي عملية تحقق أو دفع عبر API.

### ملاحظة تقنية

الترخيص المحلي يمنع المشاركة العفوية للملف بربطه بمعرّف التثبيت والتحقق من توقيعه وتاريخ انتهائه، لكنه ليس DRM غير قابل للكسر. لا يمكن من دون خادم منع تغيير ساعة الجهاز أو إلغاء ترخيص مُصدر عن بُعد أو منع تعديل JavaScript من مستخدم متقدم.

## فرع التطوير

تُنفذ أعمال نموذج الترخيص والتحصين على `chore/manual-license-hardening`. لا تدمج التغييرات إلى `main` قبل اكتمال CI واختبارات التفعيل ومراجعة معاينات Vercel.
